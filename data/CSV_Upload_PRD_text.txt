1.  Feature Overview
1.1  What This Addendum Covers
The NEUROGUT v1.0 and v2.0 PRDs established a world-class Gut-Brain Axis diagnostic platform with manual 13-taxon slider input and a researcher batch route (/research/batch). However, the live website currently lacks a fully implemented CSV Upload feature — the ability for clinicians and researchers to upload structured CSV files containing one or more patient microbiome samples for automated batch prediction.

This addendum specifies the complete CSV Upload feature as a production-ready, self-contained module that integrates with the existing v2.0 tech stack.

1.2  Problem Statement
Clinicians processing multiple patients per session cannot feasibly enter 13 taxon values manually for each patient.
Labs and sequencing facilities deliver microbiome data as CSV exports — the platform must accept this format natively.
Researchers running validation studies need to submit 10–500 samples per batch without per-record manual entry.
The existing /research/batch route is defined in the site map but has no detailed spec for validation, parsing, preview, or error recovery.
