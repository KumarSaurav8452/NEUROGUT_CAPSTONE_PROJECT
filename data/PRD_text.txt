1. Project Overview & Problem Statement
1.1 What is NEUROGUT?
NEUROGUT is an AI-powered clinical decision support platform that analyzes gut microbiome composition to predict neuropsychiatric conditions — specifically Depression and Anxiety — via the Gut-Brain Axis (GBA). It is designed as a hospital-facing SaaS tool that enables clinicians, gastroenterologists, and psychiatrists to submit a patient's microbiome sample data and receive a multi-label probability prediction, biomarker explanation, and clinical risk report.
1.2 The Clinical Problem
Current psychiatric diagnosis relies heavily on subjective self-reporting (PHQ-9, GAD-7) and clinical interviews. No objective biomarker-based test exists at the point of care for Depression or Anxiety. Emerging research in the gut-brain axis demonstrates that gut microbiota composition is directly correlated with neuropsychiatric states. NEUROGUT bridges this gap.
Key challenges the platform addresses:
Lack of objective biomarker-driven psychiatric screening tools in clinical settings
High comorbidity rate between Depression and Anxiety (45-75% overlap) — existing tools treat them as separate binary diagnoses
Clinicians lack interpretability tools to understand which bacterial taxa drive a given prediction
No standardized gut microbiome reporting workflow exists in hospital IT systems

2. ML Model Architecture & Testing Strategy
2.1 The Champion Model: GutMicrobiomeStacker
The best-performing model in new_pathway_pipeline.ipynb is the GutMicrobiomeStacker — a custom probabilistic ensemble that combines:
Component
Description
Base Model 1 — RF
MultiOutputClassifier wrapping RandomForestClassifier — captures non-linear interactions, averaged feature importances across Depression/Anxiety outputs
Base Model 2 — XGB Chain
ClassifierChain(XGBClassifier) — models label dependency: first predicts Depression, then uses Depression_Context as an extra feature to predict Anxiety. This is the key innovation.
Meta-Learner
MultiOutputClassifier(LogisticRegression) — stacks RF and XGB probability outputs and learns an optimal weighted combination
Feature Set
13 Boruta-selected bacterial taxa: Lachnospira, Ruthenibacterium, Veillonella, Gardnerella, Pseudobutyrivibrio, Kocuria, Trueperella, Lancefieldella, Fructilactobacillus, Lachnoanaerobaculum, Corynebacterium, Raoultella, Lawsonella
Training Data
111 samples (SMOTE-Tomek resampled, balanced: 37 Healthy / 37 Depression Only / 37 Comorbid)

2.3 Model Testing Plan — Synthetic Data Strategy
Since original training data is limited to 111 SMOTE samples and raw clinical data cannot be shared externally, testing will use a two-track approach:
Track A: Synthetic Data Generation (Primary Testing Track)
Use the SDV (Synthetic Data Vault) library's GaussianCopulaSynthesizer to generate statistically faithful synthetic microbiome samples from the existing X_resampled.csv distribution. This produces test data that:
Preserves marginal distributions of all 13 bacterial taxa
Preserves inter-feature correlations (critical — gut taxa are co-regulated)
Can produce arbitrarily large test sets (100–10,000 samples)
Is not traceable to any real patient, satisfying HIPAA/DISHA compliance
Implementation steps:
Install SDV: pip install sdv
Load X_resampled.csv + y_resampled.csv
Fit GaussianCopulaSynthesizer on X_resampled (features only)
Generate N=500 synthetic samples
Apply the same StandardScaler fitted on training data
Run GutMicrobiomeStacker.predict() and predict_proba()
Compute: hamming_loss, roc_auc_score, classification_report on known-label synthetic data
Visualize: plot_feature_consensus, plot_consensus_radar, plot_dysbiosis_signature on synthetic batch
Synthetic Data Code Template (SDV)
from sdv.single_table import GaussianCopulaSynthesizer
from sdv.metadata import SingleTableMetadata
metadata = SingleTableMetadata()
metadata.detect_from_dataframe(X_resampled)
synthesizer = GaussianCopulaSynthesizer(metadata)
synthesizer.fit(X_resampled)
synthetic_X = synthesizer.sample(num_rows=500)
# Assign synthetic labels using the stacker
synthetic_y = stacker.predict(synthetic_X)
synthetic_proba = stacker.predict_proba(synthetic_X)
# Evaluate
print(classification_report(known_labels, synthetic_y))
print('Hamming Loss:', hamming_loss(known_labels, synthetic_y))
print('ROC-AUC:', roc_auc_score(known_labels, synthetic_proba, average='macro'))
Track B: Edge Case & Robustness Testing (Secondary Track)
Manually construct adversarial samples representing clinical edge cases:
Edge Case
Construction Method
Extreme dysbiosis — all pathogenic taxa maxed
Set Gardnerella=1.0, Veillonella=1.0, Corynebacterium=1.0, others=0 — expect Comorbid prediction
Near-healthy — all protective taxa maxed
Set Lachnospira=1.0, Pseudobutyrivibrio=1.0, others=median — expect Healthy
Anxiety-only signature
Spike Fructilactobacillus only (Comorbid marker), suppress Depression drivers — test label separation
Missing taxa simulation
Zero out 3–5 features to simulate incomplete 16S rRNA sequencing data
Identical inputs — stability test
Submit same sample 100 times — verify deterministic output
Out-of-distribution test
Values >2 SD from training distribution — expect model to flag uncertainty

7.2 Key Components
Component
Specification
<RiskCard>
Props: condition (Depression|Anxiety), probability (float), label (0|1). Renders: large probability gauge (0-100%), risk tier badge (Healthy/Moderate/High), animated fill bar. Color changes by tier.
<BiomarkerRadar>
Plotly polar chart. Props: rf_importances, xgb_importances, feature_names. Renders overlapping RF (green) and XGB (red) normalized importance polygons. Top 8 consensus features shown.
<DysbiosisHeatmap>
Recharts HeatMap or Plotly heatmap. Rows = 13 taxa, Columns = 4 conditions (Healthy/Depression/Anxiety/Comorbid). Color scale: white (low) → teal (high abundance).
<VennDiagram>
SVG-based Venn showing overlap of RF top-5 and XGB top-5 features. Intersection labeled as 'Consensus Biomarkers'. Uses D3.js.
<SampleInputForm>
13 labeled sliders (0.0–1.0) with bacterium name, info tooltip, and live value display. Tabs to switch between Manual and CSV Upload modes. Real-time validation.
<PredictionTimeline>
Patient profile component. X-axis = date, Y-axis = depression/anxiety probability. Line chart showing risk evolution across multiple samples.
<ReportButton>
Disabled until prediction complete. Shows loading spinner during PDF generation. Triggers download on completion.
